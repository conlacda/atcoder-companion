### Calculate the average performance of a user
Get the performance history of a user at
* `https://atcoder.jp/users/<username>/history/json` - algo contest
* `https://atcoder.jp/users/<username>/history/json?contestType=heuristic` - heuristic contest

We notice at `Performance` and `InnerPerformance` with **Performance = max(Max_performance, InnerPerformance)**

In a contest, we define the maximum performance that a user can get. Specifically:

| Contest type   | Max performance  |
|---|---|
|  ABC | 2400  |
|  ARC | 2800 (div 2) or 3200 (div 1) |
| AGC | INF |
| AHC | INF |

From the API, we can get the array of inner performance of a user `[InnerPerfi1, InnerPerfi2, InnerPerfi3, InnerPerfi4,...]` ordered by time (furthest has index 1).


**Formular to calculate the average performance of that user**
$$
AvgPerf = \frac{\sum_{i=1}^{k} InnerPerfi * 0.9^i}{\sum_{i=1}^{k} 0.9^i}
$$

**Note**:
* `Perfi` is the `InnerPerformance` but not Performance (Rounded Performance).
* `AvgPerf` of newcomers as below:

| Contest type   | AvgPerf of newcomers  |
|---|---|
|  ABC | 800  |
|  ARC | 1000  |
| AGC | 1200 |
| AHC | 1000 |

### Calculate the performance during a contest
After calculating the avg_perf of all participants, we calculate `a performance array P` with `P[r] indicating the performance of rank i`.

**Formula to calculate performance P of a user with rank r**
$$
\sum_{i=1}^{n} \frac{1}{1 + 6.0^\frac{P - AvgPerf_i} {400.0}} = r - 0.5
$$

* n: the number of participants

### Calculate rating
> Performance to calculate rating is **Rounded Performance** not InnerPerformance

We have 2 ways to do it:
* Calculate the rating from the last rating, performance and the number of competitions (simple but less accurate)
* Calculate based on all of the performance of a user (requires more but with higher accuracy)

**Calculate based on the last rating**:
* `last rating`: from Standing API of Atcoder `https://atcoder.jp/contests/<contest>/standings/json` (Rating field)
* `predicted_performace = P[r]`: `P` is the performance array calculated above, `r` is the rank of the user. (Calculate the performance during a contest section)
* `the number of competitions`: from Standing API of Atcoder (Competitions field)

Code can be checked at: `rating.js > calc_rating_from_last` of the `atcoder-companion` repository

**Calculate based on all of the performance of a user**:
* All performance history before the running contest
* `predicted_performace = P[r]`: same as above

Merge them we have the supposed performance after the current contest `P = [P1, P2, ..., Pn, predicted_performace]`

Code can be checked at: `rating.js > calc_rating` of the `atcoder-companion` repository
